RULE 1
Countable vs uncountable
Can you count it? 🔢
✅ Countable
an egg → two eggs
a plate, a banana, a sandwich
has singular & plural
🚫 Uncountable
rice, water, bread, sugar, cheese, food
no plural · takes a singular verb
CCQ → Can we say "two rices"? (No!) To count it we say "two bowls of rice." Can we say "three eggs"? (Yes.)

RULE 2
some / any
some & any ➕
some
✔️ positives & offers
I'd like some water.
Would you like some cake?
any
❓ questions & ➖ negatives
Is there any milk?
There isn't any bread.
💡 Both work with countable and uncountable nouns: some apples / some rice.

MFP
Meaning · Form · Pronunciation
Get it right — M·F·P
"How much / How many…?"
MEANING = asking about quantity · FORM much + uncountable, many + countable · PRON much /mʌtʃ/, many /ˈmeni/
"I'd like some water." / "Is there any milk?"
MEANING = an unspecified amount · FORM some (+/offer), any (–/?) · PRON weak some /səm/
"a little sugar / a few olives"
MEANING = a small, positive amount · FORM a little + uncount, a few + count · PRON weak a /ə/
