RULES / NECESSITY
"Phones must be turned off during class."
"Forms must be completed in capital letters."
ABILITY / ADVICE
"This error can be fixed easily."
"Feedback should be given after each task."
💡 Key: modal + be + V3. The "be" never disappears — "must turned off" → "must be turned off". That's the most common mistake! ⚠️

Passive Voice · Part 207 / 11
BY
When to include the agent · and when to skip it
Use by only when the agent matters 👤
✅ USE "BY" — agent is important
"The report was written by the manager."
"The song was composed by Beethoven."
→ Knowing WHO matters.
✗ SKIP "BY" — agent is unknown / obvious / unimportant
"The window was broken." (we don't know)
"The homework must be submitted." (obvious)
→ WHO doesn't add information.
💡 Test: ask yourself "Does knowing who did it add something useful?" If yes → add by. If no → leave it out. Most of the time, we leave it out!
Passive Voice · Part 208 / 11
READ ALOUD
Read in pairs · passive in real conversations
🏫 School — exam week
A: Has the essay been graded yet?
B: Not yet. It will be corrected by Friday.
A: And the project — has it been submitted?
B: Yes, it was sent yesterday. Phones must be turned off during the exam, by the way!
A: I know, I know. Can it be taken in silent mode?
B: No — it must be left outside!
💼 Work — project update
A: Has the report been sent to the client?
B: Not yet. It will be sent this afternoon.
A: And the budget — has it been approved?
B: Yes! It was approved by the director.
A: Great. The invoices must be paid by Monday.
B: Already done — they were processed this morning.
🎯 Swap roles and read again. After each passive, say which pattern it uses — present perfect / future / modal / past simple!
