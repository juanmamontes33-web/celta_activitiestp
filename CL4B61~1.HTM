FORM
How it works · flip it
The tag is the opposite 🔄
Positive → negative tag
The planet is warming, isn't it?
Negative → positive tag
You don't recycle, do you?
Use the auxiliary / modal from the sentence — is, don't, can, will, have. No auxiliary? Use do / does / did. Always match the pronoun.

LANGUAGE
Language feedback · MFP
Get it right 🛠️
Common errors
amn't I → aren't I · isn't it after a negative → is it
Special cases
I'm… → aren't I? · Let's… → shall we? · Recycle! → will you? · There's… → isn't there?
Intonation
↘ falling = expecting "yes" (most common in chat) · ↗ rising = a genuine question
Negative words
never / nobody / nothing = negative → positive tag: Nobody recycles, do they?
