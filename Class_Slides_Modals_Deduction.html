FORM
How it works · how sure?
Three levels of certainty 🎯
must = I'm sure it's true   →   He must be rich.
can't = I'm sure it's NOT true   →   She can't be broke.
might / may / could = maybe   →   They might be saving.
Present: modal + be / verb  ·  Past: modal + have + past participle — He must have won the lottery.

LANGUAGE
Language feedback · MFP
Get it right 🛠️
Common errors
must to be → must be · must has won → must have won
must ≠ can't
For "impossible", use can't, never mustn't.
She can't be broke.
Pronunciation
weak have → /əv/: "must've won" · "can't've paid".
Present vs past
now: must be · before: must have been / have saved
