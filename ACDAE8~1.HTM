Question tags — the conversational hook 🪝
Positive → negative tag
Plastic is a big problem, isn't it?
Negative → positive tag
You don't recycle, do you?
Rule: use the auxiliary / modal from the statement; if there isn't one, use do / does / did. Match the pronoun.
Special cases: I'm → aren't I? · Let's… → shall we? · Imperatives → will you? · There's… → isn't there?
Intonation: voice ↗ = a real question · voice ↘ = "you agree, right?"
